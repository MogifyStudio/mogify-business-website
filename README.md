# Mogify Studio — Business Website

**Live demo:** [https://mogify-business.sites.tab.bot/](https://mogify-business.sites.tab.bot/)

The professional business website for **Mogify Studio**, a creative and digital product studio in Karachi, Pakistan. Clients can explore services, compare packages, see the portfolio and send a complete project brief straight to WhatsApp with the interactive **Project Planner**.

## Features

- **25 pages**: home, services overview + 9 individual service pages, packages, planner, work, about, contact, FAQ, privacy, terms, 404 and concept work pages
- **Packages / Pricing**: 3 tiers (Starter / Growth / Premium) for each of the 9 services, a comparison table and add-ons; every "Get a quote" button opens WhatsApp with the package name prefilled
- **Project Planner**: a 7-step brief builder (services, goals, features, style, timeline, budget range, contact) with a live summary card and estimated scope; one tap sends the brief to WhatsApp or email
- **Brand Playground**: visitors type their business name and preview it on a card, social post and website header
- **Urdu / English toggle** for key calls to action
- **Portfolio** of real Mogify work (websites, logos, branding, motion)
- Mobile-first, fast, no horizontal scroll on phones
- **SEO**: unique title/description per page, canonical URLs, Open Graph / Twitter cards, JSON-LD (ProfessionalService, Service, FAQPage), sitemap.xml, robots.txt

## Tech stack

Static HTML/CSS/JS generated by a Python build script (no framework, no backend). Font: Manrope. Brand colours: white, teal `#00A99D`, navy `#121927`.

- No backend: forms and the planner send briefs through `wa.me` (WhatsApp) and `mailto:` links.

## Run locally

Requires Python 3.8+ (standard library only).

```bash
git clone https://github.com/MogifyStudio/mogify-business-website.git
cd mogify-business-website

# preview the site (supports the clean URLs used on the live site, e.g. /about)
python3 serve.py            # → http://localhost:8000

# regenerate the pages after editing content.py / work.json / build.py
python3 build.py
```

A plain `cd site && python3 -m http.server` also works for the home page, but pretty URLs like `/about` need `serve.py` (or any host that maps `/about` → `about.html`).

## How to change prices

All prices (and the WhatsApp number / email the site uses) live in **one object**: `site/assets/js/config.js` → `window.MOGIFY`.

```js
window.MOGIFY = {
  whatsapp: "923232194013",
  email: "mogifystudio@gmail.com",
  noPriceText: "Price on request",
  prices: {
    web:  { starter: "PKR 45,000", growth: null, premium: null },  // prices[serviceId][tierId]
    logo: { starter: null, growth: null, premium: null },
    // service ids: web, logo, brand, uiux, motion, anim3d, social, book, video
    // tier ids:    starter, growth, premium
  },
  addons: { "extra-page": null, "urdu-version": null, /* ... */ }
};
```

- `null` shows **"Price on request"**; a string is shown exactly as written (`"PKR 45,000"`, `"From $299"`).
- No rebuild needed — just redeploy the `site/` folder.

## How to change the domain

Open `build.py` and change the single line:

```python
BASE_URL = "https://mogify-business.sites.tab.bot"   # no trailing slash
```

then run `python3 build.py`. Canonical URLs, Open Graph tags, JSON-LD, `sitemap.xml` and `robots.txt` all follow it.

## Deploy

`site/` is a plain static folder — upload it to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages with clean-URL support, cPanel, etc.). The live demo is published as `mogify-business`.
